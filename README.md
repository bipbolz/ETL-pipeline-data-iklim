# ETL Pipeline Data Iklim

Project ini merupakan implementasi proses ETL (Extract, Transform, Load) untuk pengolahan data iklim menggunakan Python dan PostgreSQL.

## Teknologi
- Python
- Pandas
- NumPy
- PostgreSQL
- Google Colab
- Metabase

## Tahapan ETL
1. **Extract:** Mengambil data iklim dari file CSV.
2. **Transform:** Membersihkan dan mengolah data.
3. **Load:** Memasukkan data hasil transformasi ke PostgreSQL.
4. **Visualization:** Menampilkan hasil pengolahan melalui Metabase.
